# Metodologia do Projeto

## 1. Introdução
A metodologia deste projeto consiste na organização, identificação, registo e controlo dos equipamentos de rede existentes numa infraestrutura informática.

O trabalho será desenvolvido por etapas, de forma a garantir a organização dos dados e a facilidade de consulta e atualização do inventário.

## 2. Etapas da Metodologia

### 2.1. Levantamento dos equipamentos de rede
Identificação dos equipamentos existentes na infraestrutura informática, incluindo routers, switches, firewalls, access points, servidores, bastidores de rede e outros equipamentos de comunicação.

### 2.2. Recolha das informações técnicas
Recolha dos dados técnicos de cada equipamento, incluindo marca, modelo, número de série, endereço IP, endereço MAC e localização física.

### 2.3. Identificação e classificação dos equipamentos
Organização dos equipamentos de acordo com o seu tipo, características e função na infraestrutura de rede.

### 2.4. Registo dos dados no inventário
Introdução das informações recolhidas no ficheiro CSV, garantindo que os dados ficam organizados e identificados.

### 2.5. Organização da documentação
Criação e organização dos documentos técnicos do projeto através de ficheiros Markdown, utilizando o GitHub para armazenamento e versionamento.

### 2.6. Atualização e manutenção dos registos
Atualização das informações dos equipamentos sempre que existam alterações, substituições ou intervenções de manutenção.

## 3. Organização dos Dados
Os dados serão organizados num ficheiro CSV, permitindo consultar e atualizar as informações dos equipamentos.

## 4. Ferramentas Utilizadas
- GitHub
- Git
- CSV
- Markdown

## 5. Segurança
Os dados de acesso, palavras-passe, chaves privadas e outras informações confidenciais não devem ser incluídos no repositório.

## 6. Resultado Esperado
Obter um inventário organizado e atualizado, que facilite a administração da rede, a consulta das informações e a manutenção da infraestrutura informática.
